Export

A settings file holds your Always show and Also hide accounts, each bot's choice, and whether posts that tag a hidden bot are hidden.

It never holds muting on or off, the number of mutes a day, the account muting runs as, the list address, pause or your labels.

The list is a text file with one handle per line. Anyone can import it into their own Also hide.

Import

Import adds accounts and never removes one. A settings file also sets the bot choices and tag setting it holds. It never turns muting on and never changes the number of mutes a day. Nothing changes until you confirm.

Your settings changed since this preview, so it was made again. Check it before importing.

    Exported files stay where you save them, and import reads only the file you pick. Nothing is sent anywhere. How AI Anti-Slop works
